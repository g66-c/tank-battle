# 坦克大战 · Battle City

一个使用原生 HTML5 Canvas 编写的经典坦克大战（Battle City）网页游戏。单文件实现，无需任何依赖，双击即可游玩。

## 🎮 玩法

- 控制己方坦克，消灭所有敌方坦克
- **保护基地**（地图底部的 ★ 图标），基地被摧毁则游戏结束
- 每关 20 辆敌方坦克，最多同时在场 4 辆
- 击毁砖墙开路，钢墙不可破坏，水面坦克无法通过

### 敌方坦克类型

| 类型 | 颜色 | 特点 | 得分 |
|------|------|------|------|
| 基础 | 灰 | 普通 | 100 |
| 快速 | 蓝 | 移动快 | 200 |
| 强化 | 绿 | 子弹更快 | 300 |
| 装甲 | 红 | 4 点生命，随血量变色 | 400 |

## 🕹 操作

| 按键 | 作用 |
|------|------|
| 方向键 / WASD | 移动 |
| 空格 / J | 开火 |
| P | 暂停 / 继续 |

移动端会显示虚拟方向键与开火按钮。

## 🚀 运行

直接打开 `index.html` 即可游玩，或通过任意静态服务器托管：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 🛠 技术栈

- 原生 JavaScript（ES6）
- HTML5 Canvas 渲染
- Web Audio API 音效
- 无第三方依赖
